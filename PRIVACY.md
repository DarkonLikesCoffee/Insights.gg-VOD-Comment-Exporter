# Privacy Policy

**Last updated: August 2026**

## Overview

Insights.gg VOD Comment Exporter is a free Chrome extension that allows users to copy and export comments and replies from Insights.gg VOD reviews.

## Data processing

The extension accesses and processes the content of Insights.gg VOD reviews when the user uses the extension.

This may include:

- VOD review comments
- Comment replies
- Comment timestamps
- User aliases associated with comments
- Comment formatting
- Audio comment information

The extension processes this information locally in the user's browser in order to generate the requested export.

## Data collection

The extension does **not** collect or store VOD review comments or other review content on any server operated by the developer.

The extension does not use Google Analytics or any other analytics, advertising, or tracking service.

## Data sharing

The extension does not sell, transfer, or share user data with third parties.

The information accessed by the extension is used only for its single purpose: allowing the user to copy or export Insights.gg VOD review comments and replies.

## Permissions

The extension requests access to Insights.gg because it needs to read the VOD review content required to perform the export.

The `clipboardWrite` permission is used only when the user chooses to copy exported content to their clipboard.

## Changes to this policy

This privacy policy may be updated if the functionality of the extension changes.

Any changes will be reflected in this document.
